## Featured work

**[microGPT Visualizer](https://github.com/Sjs2332/microGPT_Visualizer)**
Interactive transformer architecture explainer for Karpathy's microGPT. Type input and watch tokenization, embeddings, and attention heads update live.
`35 stars` · `real-time visualization` · `TypeScript + React`

**[AuctionMatch](https://github.com/Sjs2332/Auctionmatch)**
Vectorized auction analysis engine that learns purchase patterns, ingests live inventory via async pipelines, and outputs scores plus bid limits.
`500k+ listings` · `~3s scan time` · `async data pipelines`

**[Text-to-.step](https://github.com/Sjs2332/Text-to-.step)**
Natural language to production-ready parametric CAD (STEP/STL). Self-correcting LLM pipeline with containerized FreeCAD execution and automatic error recovery.
`82% accuracy` · `<$0.01/gen` · `30-60s execution`

**[TokenAudit](https://github.com/Sjs2332/ai-cost-calculator)**
Privacy-first token and cost telemetry for LLM sessions. Stateless reverse-proxy architecture with no database and no server-side key storage.
`~500 req/s` · `real-time cost per turn` · `keys never stored`

**[FireShrink](https://github.com/Sjs2332/Fireshrink)**
Streaming CLI that retroactively compresses Firebase Storage media with backpressure control. Safety-checked processing for images and videos.
`72K+ assets` · `98.6% reduction` · `stream-based with backpressure`

**[Local Voice Agent](https://github.com/Sjs2332/Local-voice-agent)**
Hybrid voice agent on Apple Silicon with local STT/TTS and cloud LLM, engineered around strict latency budgets.
`~4.2s end-to-end` · `STT 0.8-1.5s` · `TTS 0.9-1.6s`
